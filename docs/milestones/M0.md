## Architecture boundary

`app` invokes `application` use cases and receives wired ports from `server`.
`server` chooses adapters and validated config. Inner layers cannot import
adapters, server, framework code, or vendor SDKs. Vendor SDK imports are allowed
only under `adapters`. Time enters through `ClockPort`.
See [the full dependency table](../architecture.md).
