Derivation precedence:

1. Turn 1 COMPLETE_LIKELY → INDEPENDENT_REDISCOVERY, even though the required
   CONSOLIDATE prompt and second reasoning turn still follow.
2. Otherwise final merged learner state COMPLETE_LIKELY → GUIDED_ARRIVAL. This
   reuses the existing required-node/blocking-node/lock-threshold resolver.
3. Otherwise at least one required node DISCOVERED, or at least two distinct
   required nodes PARTIAL → PARTIAL_CAPTURE. Optional nodes do not qualify;
   a misconception does not erase genuine progress on other required nodes.
4. Otherwise → REVEAL_CONNECTION, a neutral new connection rather than failure.

### Turn 1 provenance and persistence

M4 already atomically persists the first adaptive guidance decision as
`adaptive-v1:1:<learner-state>:<action>:<target>`. Its state is calculated after
Turn 1 semantic merge, before Turn 2; COMPLETE_LIKELY maps to CONSOLIDATE with
empty target. Turn 2 writes a separate key and does not replace this event.
Existing PostgreSQL reload retains the key while reconstructing approved text.
The outcome uses the validated key, not mutable guidance wording or the final
merged state as a lossy Turn 1 proxy. Exactly one valid Turn 1 key and two turns
are required for adaptive outcome derivation; missing/ambiguous/invalid provenance
raises an explicit error rather than fabricating independence.

No new snapshot, column, table, DB migration, or provider port is required.
M4's outstanding local DB migration/persistence check remains mandatory before M9;
this provider-free gate neither applies migrations nor claims DB/hosted validation.

## M5-B — Personalized Reveal Connection — COMPLETE

Provider calls = **0**. Personalization is deterministic and evidence-grounded;

### Versioned content and storage

Conway v7 is schema version 5, extending adaptive schema v4 with
`REVEAL_CONTENT.personalized_reveal`:

```text
contract_version: personalized-reveal-v1
concept_order: [TEAM_BOUNDARIES, COMMUNICATION_FRICTION, DECISION_CLUSTERING, SYSTEM_RESEMBLANCE]
by_node: nodeId -> { label, discovered, partial, contradicted }
```

Every required node is covered, optional DECISION_CLUSTERING is included, unknown
IDs/empty strings/duplicate or incomplete ordering are rejected. Mapping strings
are Reveal-only. PUBLIC_PLAY, Judge rubric and adaptive guidance retain their
pre-Reveal identity guards. v7 preserves v6's runtime policy (max_turns 2), Judge,
PUBLIC_PLAY and canonical explanation, with no Final Synthesis policy added.
v7 and v6 remain UNSCHEDULED; no schedule bytes changed.

The four content layers remain intact. Mapping belongs inside existing Reveal
JSON and is stored/hash-bound with that immutable version; no DB table, column,
migration or new port is needed. v5/v6 bytes and research/runtime evidence remain
unchanged. The M9-required local DB migration/persistence verification remains open.

### Evidence and selection

Exact excerpt text is sliced from the referenced persisted thought using validated
integer UTF-16 offsets; no invented quote, paraphrase or summarization is permitted.
Missing/ambiguous thought, invalid bounds/empty span/split surrogate and missing
evidence omit the candidate. Currently endorsed CONTRADICTED uses only its
contradictionEvidence, never stale positive evidence. Excerpts over 240 Unicode
characters are omitted entirely instead of being truncated or displayed as a
2,000-character response. Internal omission categories contain no raw text or
node IDs; the authorized route logs only the sanitized category.

Select at most **two** items. Positive candidates rank DISCOVERED before PARTIAL;
within status use deepest Reveal concept_order first. Preserve the best positive
item, then reserve at most one slot for the deepest valid required contradiction.
Deduplicate by exact excerpt text, including identical text from different answers;
keep the highest-priority/deeper positive candidate. Divergence sharing the positive
quote cannot erase that progress. Fill any remaining slot with the next distinct
positive candidate. Optional contradictions do not reserve slots. No positive
evidence is required: zero items is valid, including REVEAL_CONNECTION.

### Public view and UI

`personalizedConnection: { items: [{ label, userExcerpt, explanation }], canonicalInsight }`.

three-second choreography was implemented; that belongs to M5-C.
